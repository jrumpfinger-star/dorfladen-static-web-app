Dorfladen Kiosk – Handbuch

Praxisnahe Anleitungen für den täglichen Ladenbetrieb. Alle Bezeichnungen entsprechen den Schaltflächen und Filtern im Kiosk.

Überblick

Der Kiosk bündelt die Aufgaben, die während eines Verkaufstags regelmäßig anfallen. Wählen Sie oben den passenden Bereich. Zahlen oder farbige Hinweise an einem Bereich machen auf neue oder noch offene Vorgänge aufmerksam.

Szenario: Arbeitsbeginn im Laden

Sie übernehmen den Kiosk zu Beginn Ihrer Schicht.

  1. Prüfen Sie Datum und Uhrzeit in der Kopfzeile.
  2. Sehen Sie nach, an welchen Hauptbereichen Zahlen oder farbige Hinweise angezeigt werden.
  3. Bearbeiten Sie zuerst neue Bestellungen und ungelesene Nachrichten. Prüfen Sie danach Vorgänge mit bevorstehender oder überschrittener Abholzeit.
  4. Verwenden Sie Aktualisieren, wenn Sie den Datenstand sofort neu laden möchten.

Ergebnis: Sie haben einen geordneten Überblick über neue, offene und zeitkritische Aufgaben.

Szenario: Eine Schaltfläche oder ein Status ist unklar

  1. Öffnen Sie über das Fragezeichen dieses Handbuch.
  2. Wählen Sie oben das Kapitel des betroffenen Kiosk-Bereichs.
  3. Vergleichen Sie den Status und die Schaltflächen mit dem dargestellten Standardablauf.
  4. Prüfen Sie vor einem Storno oder endgültigen Löschen immer Name, Bestellnummer und Begründung.

Wichtig: Nicht jede Aktion ist rückgängig zu machen. Beachten Sie deshalb Bestätigungsfenster, insbesondere beim Löschen und Stornieren.

Orientierung

  • Offen: neue und bereits bestätigte Bestellungen.
  • Nachrichten: Bestellungen mit Kundenmitteilungen, die geprüft werden müssen.
  • Erledigt: abgeholte und stornierte Bestellungen.
  • Alle: vollständige Übersicht für den gewählten Tag.
  • Neue Telefonbestellung: Bestellung für einen vorhandenen oder neuen Stammkunden erfassen.
  • Küchenliste drucken: Tagesübersicht für die Vorbereitung ausgeben.

Szenario: Eine Kundin bestellt telefonisch

Frau Huber bestellt zwei Portionen des Tagesgerichts zum Mitnehmen.

  1. Wählen Sie im Mittagstisch den gewünschten Tag und tippen Sie auf Neue Telefonbestellung.
  2. Suchen Sie Frau Huber über den Namen. Ist sie noch nicht gespeichert, wählen Sie die Möglichkeit zum Anlegen und erfassen mindestens Nachname und die vorhandene Telefonnummer.
  3. Wählen Sie das Gericht und stellen Sie die Menge auf zwei.
  4. Aktivieren Sie Zum Mitnehmen. Tragen Sie einen Sonderwunsch nur dann in die Anmerkung ein, wenn er für die Zubereitung wichtig ist.
  5. Speichern Sie die Bestellung und kontrollieren Sie, ob sie beim gewählten Tag unter Offen erscheint.

Ergebnis: Die Telefonbestellung ist dem Kunden, dem Gericht und dem Abholtag zugeordnet.

Szenario: Mehrere neue Bestellungen für dasselbe Gericht bestätigen

  1. Öffnen Sie Offen. Bestellungen sind nach Gericht zusammengefasst.
  2. Prüfen Sie die Anzahl und besondere Anmerkungen innerhalb der Gerichtsgruppe.
  3. Bestätigen Sie einzelne Bestellungen über OK. Bei mehreren neuen Bestellungen können Sie die angebotene Sammelbestätigung der Gerichtsgruppe verwenden.
  4. Tragen Sie im Bestätigungsfenster bei Bedarf eine kurze Nachricht ein, etwa eine abweichende Fertigstellungszeit.

Kontrolle: Bestätigte Bestellungen bleiben unter Offen sichtbar und bieten die Aktion Abgeholt.

Szenario: Ein Gericht ist nicht mehr verfügbar

  1. Öffnen Sie jede betroffene Bestellung und prüfen Sie Name, Menge und Anmerkung.
  2. Tippen Sie auf die rote Storno-Schaltfläche.
  3. Geben Sie eine klare Begründung ein, die für die weitere Bearbeitung nachvollziehbar ist.
  4. Bestätigen Sie das Storno und kontrollieren Sie die Bestellung anschließend unter Erledigt.

Eine Telefonbestellung hat nicht zwingend einen digitalen Benachrichtigungskanal. Informieren Sie den Kunden bei Bedarf zusätzlich über die hinterlegte Telefonnummer.

Szenario: Abholung und Kundenrückfrage

  1. Suchen Sie die bestätigte Bestellung unter Offen.
  2. Öffnen Sie die Karte, wenn eine Anmerkung oder Nachricht angezeigt wird. Antworten Sie über das Nachrichtenfeld, wenn eine Rückmeldung erforderlich ist.
  3. Geben Sie das richtige Gericht und die richtige Menge aus.
  4. Tippen Sie erst danach auf Abgeholt.

Szenario: Eine neue Bestellung annehmen

  1. Öffnen Sie Zu erledigen und wählen Sie die neue Bestellung.
  2. Prüfen Sie Name, Abholdatum, Zeitfenster, Positionen und Kundenanmerkungen. Über Details sehen Sie die vollständigen Angaben.
  3. Tippen Sie auf Annehmen, wenn die Bestellung bearbeitet werden kann.
  4. Ordnen Sie der Bestellung einen eindeutig beschrifteten Korb oder Behälter zu.

Ergebnis: Die Bestellung steht auf In Bearbeitung und kann über Packen geöffnet werden.

Szenario: Bestellung vollständig packen

  1. Tippen Sie bei der angenommenen Bestellung auf Packen.
  2. Legen Sie jeden Artikel in den Behälter und haken Sie ihn in der Packliste ab.
  3. Prüfen Sie den Fortschritt. Änderungen werden während der Bearbeitung gespeichert.
  4. Nutzen Sie bei Bedarf Drucken, wenn Sie mit einer Papierliste arbeiten möchten.
  5. Schließen Sie die Packliste erst ab, nachdem Artikel und Mengen kontrolliert wurden.

Ergebnis: Die Bestellung wechselt auf Abholbereit.

Szenario: Ein Artikel fehlt oder ist nur teilweise verfügbar

  1. Öffnen Sie die Packliste und wählen Sie die betroffene Position.
  2. Tragen Sie die tatsächlich gepackte Menge ein. Bei Menge null wird die Position als Nicht lieferbar, bei einer kleineren Menge als Teilmenge gekennzeichnet.
  3. Kontrollieren Sie den aktualisierten Gesamtbetrag in der Packansicht.
  4. Senden Sie bei Klärungsbedarf über die Bestellung eine kurze Nachricht an den Kunden.
  5. Beenden Sie das Packen erst, wenn die Abweichung korrekt dokumentiert ist.

Szenario: Kunde holt ab oder eine Bestellung ist überfällig

  1. Für die Ausgabe öffnen Sie Heute abholen und gleichen den Namen mit dem beschrifteten Behälter ab.
  2. Prüfen Sie insbesondere dokumentierte Teilmengen und Nachrichten.
  3. Übergeben Sie die Bestellung und tippen Sie anschließend auf Ausgeben.
  4. Bei nicht erfolgter Abholung öffnen Sie Überfällig, prüfen Zeitfenster und Kontaktdaten und stimmen das weitere Vorgehen mit dem Kunden ab.
  5. Abgeschlossene und stornierte Bestellungen finden Sie unter Historie; dort können Sie zwischen 7 Tagen, 30 Tagen und allen Einträgen wählen.

Ein versehentlich weitergesetzter aktiver Status kann über die Zurück-Funktion korrigiert werden. Prüfen Sie vorher, welcher Bearbeitungsstand tatsächlich gilt.

Metzger

Dieser Bereich verwaltet Fleischvorbestellungen nach Liefertag. Sie kennzeichnen, welche Positionen beim Lieferanten bestellt wurden, beantworten Kundenmitteilungen und schließen die Bestellung bei Abholung ab.

AlleBestelltAbgeholtAntworten

Was die Zustände bedeuten

  • Neu: Mindestens eine Position muss noch beim Metzger bestellt werden.
  • In Bestellung: Alle Positionen sind als beim Metzger bestellt markiert.
  • Abgeholt: Die Kundin oder der Kunde hat die Ware erhalten.
  • Storniert: Die Bestellung wurde mit einer Begründung beendet.

Szenario: Neue Fleischvorbestellungen einzeln bearbeiten

  1. Öffnen Sie Zu erledigen. Die Bestellungen sind nach Liefertag gruppiert.
  2. Klappen Sie eine Bestellung auf und prüfen Sie Artikel, Zuschnitt, Kilogramm-Angabe und Anmerkung.
  3. Haken Sie jede Position ab, sobald sie beim Lieferanten bestellt wurde. Mit Alle können Sie alle offenen Positionen dieser Bestellung markieren.
  4. Sobald alle Positionen markiert sind, wechselt die Bestellung auf In Bestellung.

Kontrolle: Der Zähler zeigt, wie viele Positionen bereits bearbeitet wurden.

Szenario: Sammelbestellung für einen Liefertag erstellen

Mehrere Kunden haben Fleisch für denselben Liefertag vorbestellt.

  1. Öffnen Sie Sammelbestellung und wählen Sie bei mehreren Terminen den richtigen Liefertag.
  2. Prüfen Sie die zusammengefassten Positionen mit Artikel, Kunde, Zuschnitt und Kilogramm-Angabe.
  3. Verwenden Sie Drucken, um ausschließlich noch offene Positionen als Bestellliste auszugeben.
  4. Markieren Sie einzelne Positionen nach der Übermittlung. Alle abhaken verwenden Sie nur, wenn wirklich alle offenen Positionen bestellt wurden.
  5. Eine falsch markierte Position können Sie über Zurücksetzen wieder öffnen.

Szenario: Kundenfrage beantworten oder Bestellung stornieren

  1. Öffnen Sie Nachrichten. Ungelesene Mitteilungen stehen vor bereits gelesenen.
  2. Lesen Sie die Nachricht im Zusammenhang mit der zugehörigen Bestellung.
  3. Tippen Sie auf Antworten, geben Sie eine eindeutige Rückmeldung ein und senden Sie diese. Markieren Sie die Nachricht danach als gelesen.
  4. Wenn die Bestellung nicht erfüllt werden kann, stornieren Sie sie unter Zu erledigen. Wählen Sie einen passenden Pflichtgrund und ergänzen Sie bei Bedarf einen Kommentar.

Szenario: Fleischbestellung ausgeben

  1. Öffnen Sie am Liefertag Heute abholen.
  2. Vergleichen Sie Kundenname, Artikel und Menge mit der bereitliegenden Ware.
  3. Tippen Sie erst nach der Übergabe auf Abgeholt.
  4. Bei einem versehentlichen Abschluss können Sie den Status über Zurück korrigieren. Abgeschlossene Vorgänge finden Sie in der Historie.

Der Kiosk dokumentiert die vorbestellten Mengen und den Bearbeitungsstand bis zur Abholung.

Szenario: Einen neuen Stammkunden anlegen

  1. Suchen Sie zuerst nach Nachname oder Telefonnummer, damit kein doppelter Eintrag entsteht.
  2. Wenn kein passender Kunde vorhanden ist, tippen Sie auf Neuer Kunde.
  3. Tragen Sie Nachname und Telefonnummer ein; beide Angaben sind erforderlich. Vorname, E-Mail-Adresse und Notiz sind optional.
  4. Speichern Sie und kontrollieren Sie Name, Telefonnummer und automatisch vergebene Stammkundennummer in der Kundenkarte.

Szenario: Aus dem Kundenprofil eine Mittagstisch-Bestellung aufnehmen

Herr Maier ruft regelmäßig an und bestellt sein Tagesgericht.

  1. Suchen Sie Herrn Maier im Bereich Stammkunden.
  2. Tippen Sie an seiner Kundenkarte auf Bestellen.
  3. Der Kiosk wechselt zum Mittagstisch und übernimmt den Kunden in die neue Telefonbestellung.
  4. Wählen Sie Gericht und Menge, ergänzen Sie bei Bedarf Mitnehmen und Anmerkung und speichern Sie.

Ergebnis: Die Bestellung ist direkt mit dem vorhandenen Kunden verknüpft.

Szenario: Telefonnummer oder Notiz korrigieren

  1. Öffnen Sie die Kundenkarte und tippen Sie auf Bearbeiten.
  2. Ändern Sie die betroffenen Angaben. Nachname und Telefonnummer müssen weiterhin ausgefüllt sein.
  3. Speichern Sie und suchen Sie den Kunden erneut, um die Änderung zu kontrollieren.

Szenario: Einen nicht mehr benötigten Kundeneintrag deaktivieren

  1. Prüfen Sie sorgfältig Namen, Telefonnummer und Stammkundennummer.
  2. Tippen Sie auf die rote Deaktivieren-Schaltfläche.
  3. Bestätigen Sie Deaktivieren nur für den richtigen Datensatz.

Wirkung: Der Kunde wird deaktiviert und nicht mehr in der normalen aktiven Suche angeboten. Dies ist keine Buchung und keine Bearbeitung vergangener Bestellungen.

Social Media und Tagesinfo

Der Social-Bereich erstellt aus Titel, Text und ausgewählten Produkten ein fertiges Poster. Sie können es je nach Gerät teilen, als Bild speichern, als Tagesinfo auf der Homepage veröffentlichen oder als Entwurf parken.

Der Ablauf in vier Schritten

  1. Titel & Text: Wählen Sie Heute oder Morgen, einen vorgeschlagenen Titel oder einen eigenen Titel und ergänzen Sie bei Bedarf einen kurzen Begleittext.
  2. Produkte auswählen: Wählen Sie passende Katalogprodukte, Mittagstisch-Gerichte oder freie Einträge. Beschränken Sie sich auf die Informationen, die im Beitrag wirklich benötigt werden.
  3. Vorschau: Prüfen Sie Schreibweise, Datum, Preis, Bild, Auswahl und Lesbarkeit.
  4. Teilen & Veröffentlichen: Entscheiden Sie bewusst zwischen externem Teilen, Bildspeicherung, Homepage-Veröffentlichung und Entwurf.

Szenario: Einen Tagesbeitrag für frische Ware erstellen

Heute sind Erdbeeren und Bauernbrot eingetroffen.

  1. Öffnen Sie Neuer Post und wählen Sie Heute.
  2. Wählen Sie beispielsweise den Titel Frisch eingetroffen und ergänzen Sie einen sachlichen Text wie „Heute frisch geliefert – nur solange der Vorrat reicht.“
  3. Wählen Sie Erdbeeren und Bauernbrot aus dem Katalog.
  4. Öffnen Sie die Vorschau und kontrollieren Sie Produktnamen, Preise und Bilder.
  5. Wählen Sie danach den gewünschten Ausgabeweg.

Szenario: WhatsApp oder Instagram verwenden

  1. Erstellen und prüfen Sie zuerst die Vorschau.
  2. Tippen Sie auf Auf WhatsApp teilen oder Auf Instagram teilen.
  3. Auf Smartphones und Tablets kann sich die Teilen-Auswahl des Geräts öffnen. Wählen Sie dort die gewünschte App und anschließend Empfänger oder Status.
  4. Wenn das Gerät keine direkte Dateifreigabe unterstützt, wird das Poster je nach Browser heruntergeladen oder in die Zwischenablage gelegt. Öffnen Sie dann die Ziel-App selbst und fügen Sie Bild und gegebenenfalls Text ein.
  5. Prüfen Sie in der Ziel-App nochmals den endgültigen Beitrag, bevor Sie ihn absenden oder veröffentlichen.

Das Verhalten wird vom Gerät, Browser und den installierten Apps bestimmt. Eine externe App öffnet sich daher nicht auf jedem Gerät automatisch.

Szenario: Tagesinfo auf der Homepage veröffentlichen

  1. Wählen Sie Heute oder Morgen und erstellen Sie den Beitrag vollständig.
  2. Prüfen Sie in der Vorschau Datum, Titel, Freitext und Produkte.
  3. Tippen Sie auf Tagesinfo veröffentlichen.
  4. Warten Sie auf die grüne Erfolgsmeldung. Ein Beitrag für heute erscheint auf der Homepage; ein Beitrag für morgen wird für das Zieldatum geplant und laut Kiosk ab dem Vorabend angezeigt.
  5. Kontrollieren Sie den Eintrag anschließend unter Posts & Entwürfe.

Szenario: Fehler vor der Veröffentlichung korrigieren

In der Vorschau steht ein falscher Preis.

  1. Veröffentlichen oder teilen Sie das Poster noch nicht.
  2. Öffnen Sie den Schritt mit der Produktauswahl oder wechseln Sie in den Katalog, wenn die gespeicherten Produktdaten falsch sind.
  3. Korrigieren Sie die Angabe und erzeugen Sie die Vorschau erneut.
  4. Vergleichen Sie die neue Vorschau mit der Ware und dem aktuellen Preis.

Ein bereits extern geteilter Beitrag wird durch eine Korrektur im Kiosk nicht aus WhatsApp oder Instagram entfernt. Korrigieren Sie ihn zusätzlich in der jeweiligen App.

Szenario: Beitrag vorbereiten und später veröffentlichen

  1. Erstellen Sie Titel, Text und Produktauswahl.
  2. Tippen Sie auf Parken. Der Beitrag wird als Entwurf gespeichert.
  3. Öffnen Sie später Posts & Entwürfe, laden Sie den Entwurf zum Bearbeiten und prüfen Sie Aktualität und Datum.
  4. Aktualisieren Sie den Entwurf erneut mit Parken oder veröffentlichen Sie ihn über die angebotene Veröffentlichungsaktion.

Szenario: Neues Produkt im Katalog anlegen

  1. Wechseln Sie von Neuer Post zu Katalog.
  2. Prüfen Sie über Suche und Kategorien, ob das Produkt bereits vorhanden ist.
  3. Erfassen Sie Produktname, Kategorie und Preis.
  4. Fügen Sie bei Bedarf ein Bild über Kamera, Datei oder Zwischenablage hinzu.
  5. Speichern Sie das Produkt und suchen Sie es anschließend im Katalog, bevor Sie es in einem Beitrag verwenden.
  6. Fehlt eine passende Kategorie, öffnen Sie Kategorien verwalten und ergänzen Sie sie nach den im Laden verwendeten Bezeichnungen.

Kalender

Szenario: Einmalige Lieferung mit Uhrzeit eintragen

Eine Gemüselieferung kommt am Donnerstag um 08:00 Uhr.

  1. Wählen Sie in der Wochenübersicht den Donnerstag.
  2. Tippen Sie auf + Neuer Eintrag.
  3. Tragen Sie einen eindeutigen Titel ein, wählen Sie Uhrzeit und stellen Sie 08:00 Uhr ein.
  4. Wählen Sie die Kategorie Lieferung und lassen Sie die Wiederholung auf Einmalig.
  5. Speichern Sie und kontrollieren Sie den Eintrag unter Mit Uhrzeit.

Szenario: Wiederkehrende Aufgabe mit Vorlage anlegen

Die Kühltheke soll jede Woche gereinigt werden.

  1. Wählen Sie den ersten Ausführungstag und öffnen Sie + Neuer Eintrag.
  2. Wählen Sie eine passende Vorlage oder tragen Sie den Titel selbst ein.
  3. Prüfen Sie Kategorie, Ganztags/Uhrzeit und die von der Vorlage übernommenen Werte.
  4. Wählen Sie Wöchentlich. Für mehrere feste Wochentage wählen Sie Wochentage und markieren die benötigten Tage.
  5. Speichern Sie und wechseln Sie zur Folgewoche, um die Serie zu kontrollieren.

Szenario: Reservierung einem Stammkunden zuordnen

  1. Wählen Sie den Tag und öffnen Sie einen neuen Eintrag.
  2. Tragen Sie eine eindeutige Beschreibung ein und wählen Sie Reservierung.
  3. Geben Sie im optionalen Feld Kunde mindestens zwei Zeichen ein und wählen Sie den passenden Stammkunden aus der Trefferliste.
  4. Speichern Sie. Der Kundenname wird am Kalendereintrag angezeigt.

Szenario: Aufgabe erledigen und später wieder anzeigen

  1. Tippen Sie am Kalendereintrag auf das Kontrollkästchen, sobald die Aufgabe abgeschlossen ist.
  2. Erledigte Einträge werden in der normalen Ansicht ausgeblendet.
  3. Tippen Sie auf Erledigte zeigen, wenn Sie den Abschluss kontrollieren oder den Eintrag wieder öffnen möchten.

Szenario: Nur einen Termin einer Serie auslassen

Eine wöchentliche Lieferung entfällt nur an einem Feiertag.

  1. Wählen Sie den betroffenen Feiertag und tippen Sie am Serieneintrag auf den Papierkorb.
  2. Im Fenster Serie löschen? wählen Sie Nur diesen Tag.
  3. Kontrollieren Sie den Folgetermin. Die Serie läuft dort unverändert weiter.

Szenario: Eine Serie ab einem Datum beenden

Eine regelmäßige Liefervereinbarung endet zum Monatswechsel.

  1. Wählen Sie den ersten Tag, an dem der Termin nicht mehr stattfinden soll.
  2. Tippen Sie am Serieneintrag auf den Papierkorb.
  3. Wählen Sie Ganze Serie löschen. In diesem Dialog bedeutet die Aktion: Serie ab dem gewählten Datum beenden.
  4. Prüfen Sie eine spätere Woche. Ab dem gewählten Datum werden keine weiteren Vorkommen angezeigt.

Historie: Frühere Termine der Serie bleiben erhalten, einschließlich bereits erledigter Vorkommen.
