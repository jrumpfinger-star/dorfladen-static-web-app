1. Überblick & Einstieg

Was ist das Dorfladen CMS?

Das Dorfladen CMS ist eine webbasierte Verwaltungsoberfläche für den Dorfladen Oberornau. Damit verwalten Sie alle Inhalte Ihrer Website – vom Wochenplan über Angebote bis hin zu Flyern und Push-Benachrichtigungen – direkt im Browser.

Zugang

Öffnen Sie das CMS unter: https://kind-pebble-072605b03.7.azurestaticapps.net/cms.html

Oben rechts sehen Sie den Verbindungsstatus und die aktuelle Version. Über den Link „Website" gelangen Sie zur öffentlichen Seite.

Abb. 1: Die CMS-Startseite mit der Tab-Navigation am linken Rand

Navigation

Die Navigation besteht aus Tabs am linken Rand:

🕐 ÖffnungszeitenTägliche Öffnungszeiten pflegen
🏷️ AngeboteSonderaktionen mit Bildern & Preisen

Alle Änderungen werden automatisch gespeichert. Es gibt keinen separaten „Speichern"-Button – Ihre Eingaben werden sofort übernommen.

2. Wochenplan (Mittagstisch)

Abb. 2: Der Wochenplan-Tab mit Kalendernavigation

Übersicht

Im Wochenplan pflegen Sie den Mittagstisch für die aktuelle oder kommende Woche. Die Kalenderwoche und der Zeitraum werden oben angezeigt.

Bedienung

  1. Woche wählen: Nutzen Sie die Pfeile ← → oder die Buttons „Diese Woche" / „Nächste Woche"
  2. Gericht hinzufügen: Klicken Sie auf „+ Gericht"
  3. Gericht bearbeiten: Klicken Sie auf ein bestehendes Gericht, um Name, Beschreibung und Preis zu ändern
  4. Gericht löschen: Im Bearbeitungsmodus gibt es einen Löschen-Button
  5. Vorschau: Über den Button „Vorschau" sehen Sie, wie der Plan auf der Website aussieht
  6. Drucken: Der Button „🖨️ Drucken" erzeugt eine druckoptimierte Version
  7. Teilen: Der „Teilen"-Button erstellt einen Link zum Verschicken
Der Wochenplan wird automatisch auf der Website aktualisiert, sobald Sie Änderungen vornehmen.

3. Öffnungszeiten

Abb. 3: Verwaltung der Öffnungszeiten

Bedienung

  1. Für jeden Wochentag können Sie die Öffnungs- und Schließzeit eintragen
  2. Bei geschlossenen Tagen lassen Sie das Feld leer oder tragen „geschlossen" ein
  3. Änderungen werden sofort gespeichert und auf der Website angezeigt
Die Öffnungszeiten werden prominent auf der Homepage und der Detailseite dargestellt.

4. Sonderangebote / Aktionen

Abb. 4: Die Angebote-Übersicht

Neue Aktion erstellen

  1. Klicken Sie auf „+ Neue Aktion erstellen"
  2. Füllen Sie die Felder aus:
    • Produktname: z. B. „Bio-Äpfel aus der Region"
    • Preis: Angebotspreis in Euro
    • Originalpreis: (optional) für die Ersparnis-Anzeige
    • Gültig von/bis: Aktionszeitraum
    • Artikelnummer: (optional) für interne Zuordnung
    • Bild: Produktfoto hochladen (wird automatisch optimiert)
  3. Speichern – die Aktion erscheint sofort auf der Website

Filter

Mit den Buttons „Diese Woche", „Nächste Woche" und „Alle" können Sie die Ansicht filtern.

Angebote mit Bild werden automatisch für den Flyer- und Plakat-Export berücksichtigt (siehe Kapitel Design).

5. Homepage-Inhalte

Abb. 5: Bearbeitung der Homepage-Inhalte

Bearbeitbare Bereiche

  • Logo: Das Dorfladen-Logo hochladen oder austauschen
  • Begrüßungstext: Der Haupttext auf der Startseite
  • Banner-Bild: Das große Headerbild der Website
  • Slogan / Untertitel: Wird unter dem Logo angezeigt
Das Logo wird auch in der Navigation, im Footer und auf den Flyern/Plakaten verwendet.

6. Aktuelles (News)

Abb. 6: Der Aktuelles/News-Bereich

News erstellen

  1. Klicken Sie auf „+ Neuer Beitrag"
  2. Geben Sie Titel, Text und optional ein Bild ein
  3. Das Datum wird automatisch gesetzt
  4. Der Beitrag erscheint chronologisch auf der „Aktuelles"-Seite
News-Beiträge eignen sich ideal für saisonale Hinweise, Veranstaltungen oder allgemeine Mitteilungen.

Abb. 7: Das Sortiment / die Preisliste

Bedienung

8. Impressionen (Bildergalerie)

Abb. 8: Die Bildergalerie-Verwaltung

Bilder verwalten

  1. Bilder hochladen: Über den Upload-Button können Sie mehrere Bilder gleichzeitig auswählen
  2. Beschriftung: Jedes Bild kann einen Titel und eine Beschreibung erhalten
  3. Reihenfolge: Per Drag & Drop können Bilder umsortiert werden

Verwenden Sie aussagekräftige, helle Bilder. Diese werden auf der „Impressionen"-Seite der Website in einer Galerie angezeigt.

9. Push-Benachrichtigungen

Abb. 9: Push-Benachrichtigungen verwalten und senden

Was sind Push-Benachrichtigungen?

Push-Nachrichten werden direkt auf das Smartphone oder den Computer Ihrer Kunden gesendet – auch wenn die Website gerade nicht geöffnet ist. Kunden müssen dafür einmalig zustimmen.

Push-Nachricht senden

  1. Wählen Sie eine Schnellvorlage (Mittagstisch, Angebote, News) oder erstellen Sie eine eigene Nachricht
  2. Geben Sie Titel und Text ein
  3. Klicken Sie auf „Senden"
  4. Die Nachricht wird an alle angemeldeten Kunden gesendet

Schnellvorlagen

VorlageVerwendung
🍽️ MittagstischNeuen Wochenplan ankündigen
🏷️ AngeboteNeue Sonderaktionen bewerben
📰 NewsAuf neue Beiträge hinweisen

Subscriber verwalten

Im Bereich „Subscriber" sehen Sie, wie viele Kunden angemeldet sind. Einzelne Abonnements können dort auch gelöscht werden.

Push-Nachrichten sollten sparsam eingesetzt werden (max. 1–2 pro Woche), damit Kunden sich nicht abmelden.

11. Design-Editor (Flyer & Plakat)

Abb. 11: Der Design-Editor für Flyer und Plakate

Übersicht

Der Design-Editor ist eines der mächtigsten Werkzeuge im CMS. Damit erstellen Sie professionelle Angebotsflyer und Plakate direkt aus Ihren Angebotsdaten – komplett automatisch.

Layouts

LayoutBeschreibung
MagazinModernes Layout mit abgerundeten Karten
ClassicTraditionelles Layout mit klaren Linien

Ausgabeformate

  • Einzelflyer: Ein A4-Blatt pro Angebot mit großem Produktbild
  • Plakat: Alle Angebote auf einem großen Poster (A2/A3)

12. Flyer- & Kachel-Editor im Detail

Kachel-Editor (Angebotskarten)

Jede Angebotskarte kann individuell angepasst werden. Klicken Sie auf eine Karte in der Design-Vorschau, um den Kachel-Editor zu öffnen.

Bild positionieren

  • Ziehen: Klicken und Ziehen, um das Bild zu verschieben
  • Größe: Nutzen Sie den Schieberegler „🔍 Größe" oder das Mausrad
  • Drehen: Rechtsklick → „Bild drehen +15°" / „−15°"

Ghost-Effekt (Schattenkopie)

Der Ghost-Effekt erzeugt eine halbtransparente Kopie des Produktbilds im Hintergrund – ideal für einen professionellen Look.

  1. Klicken Sie auf „👻 Ghost" um den Effekt einzuschalten
  2. Der Ghost wird automatisch versetzt dargestellt
  3. Position: Ghost anklicken und ziehen
  4. Transparenz: Rechtsklick → Deckkraft anpassen (10–90%)
  5. Größe: Mausrad über dem Ghost oder Rechtsklick → Größe
  6. Drehen: Rechtsklick → Drehen

Duplikat-Effekt

Das Duplikat erzeugt eine vollständig sichtbare (100% Deckkraft) Kopie des Bilds.

  1. Klicken Sie auf „📝 Duplikat"
  2. Positionierung und Anpassung funktionieren wie beim Ghost

Weitere Kopien (Multi-Ghost/Duplikat)

Sie können unbegrenzt viele zusätzliche Ghost- oder Duplikat-Kopien hinzufügen:

  1. Klicken Sie auf „+ 👻" für eine weitere Ghost-Kopie
  2. Klicken Sie auf „+ 📝" für eine weitere Duplikat-Kopie
  3. Jede Kopie kann unabhängig positioniert, skaliert und gedreht werden
  4. Zum Löschen: Rechtsklick auf die Kopie → „Kopie löschen" oder ×-Button in der Liste
Mit mehreren Ghost-Kopien in verschiedenen Größen und Transparenzen erzeugen Sie einen attraktiven „Wasserzeichen"-Effekt.

Kontextmenü (Rechtsklick)

Ein Rechtsklick auf jedes Element öffnet ein Kontextmenü mit erweiterten Optionen:

AktionBeschreibung
↻ Drehen +15° / −15°Element in 15°-Schritten drehen
🔍 GrößeGröße prozentual anpassen (10–300%)
🔆 DeckkraftTransparenz anpassen (nur Ghost)
↩ Position zurücksetzenElement an Standardposition zurücksetzen
🗑️ Alles zurücksetzenAlle Anpassungen verwerfen
👻+ Ghost-Kopie hinzufügenNeue halbtransparente Kopie erstellen
📝+ Duplikat-Kopie hinzufügenNeue volldeckende Kopie erstellen
🖼+ Eigenes Bild einfügenEigenes Overlay-Bild hochladen (Siegel, Störer etc.)

Aktives Element

Oben wird angezeigt, welches Element gerade aktiv ist (z. B. „🖼 Bild", „👻 Ghost", „📝 Duplikat"). Das aktive Element wird mit einer gestrichelten Umrandung hervorgehoben. Klicken Sie auf ein anderes Element, um es auszuwählen.

Einzelflyer-Editor

Der Einzelflyer-Editor öffnet sich in einem neuen Fenster und bietet erweiterte Kontrolle für jedes Angebotsblatt:

Steuerelemente

Unter jedem Flyer befindet sich eine Kontrollleiste mit:

  • 🖼 Bild: Pfeilkreuz zum Verschieben des Produktbilds
  • 🏷 Preis: Pfeilkreuz zum Verschieben des Preisschilds
  • 👻 Ghost: Ein-/Ausschalten + Positions-Pfeile + Deckkraft + Größe
  • 📝 Duplikat: Ein-/Ausschalten + Positions-Pfeile + Größe
  • Weitere Kopien: „+ 👻 Ghost" und „+ 📝 Duplikat" Buttons für zusätzliche Kopien

Drag & Drop

Alle Overlay-Elemente (Bild, Preis, Ghost, Duplikat, Kopien) können direkt auf dem Flyer-Vorschaubild per Drag & Drop verschoben werden.

Eigenes Bild einfügen

Über das Kontextmenü (Rechtsklick) können Sie ein eigenes Bild als zusätzliches Overlay einfügen – z. B. ein Siegel, einen Störer oder ein Dekorationselement.

Export

  • 🖨️ Drucken: Direkt aus dem Browser drucken
  • ⬇️ Download: Als PNG-Bild speichern

13. Die Dorfladen-Website

Aufbau der Website

Die Dorfladen-Website wird automatisch aus den CMS-Daten generiert und besteht aus folgenden Seiten:

SeiteInhaltURL-Pfad
StartseiteLogo, Begrüßung, Öffnungszeiten, aktuelle Angebote/
AngeboteAlle aktuellen Sonderangebote mit Bildern/angebote.html
MittagstischAktueller Wochenplan/wochenplan.html
AktuellesNews-Beiträge chronologisch/aktuelles.html
SortimentPreisliste / Produktübersicht/preisliste.html
ImpressionenBildergalerie/impressionen.html

Progressive Web App (PWA)

Die Website ist als Progressive Web App installierbar. Das bedeutet:

  • Kunden können die Website auf ihrem Startbildschirm ablegen (wie eine App)
  • Die Seite funktioniert auch bei schlechter Internetverbindung (Caching)
  • Push-Benachrichtigungen können empfangen werden (siehe Kapitel 9)

Responsive Design

Die Website passt sich automatisch an alle Bildschirmgrößen an:

  • Desktop: Breite Darstellung mit Sidebar-Navigation
  • Tablet: Angepasstes Layout mit Touch-Optimierung
  • Smartphone: Mobile Navigation mit Hamburger-Menü und optimierten Bildergrößen
Testen Sie die Website regelmäßig auf Ihrem Smartphone, um sicherzustellen, dass alles gut aussieht.

14. Häufige Fragen (FAQ)

Allgemein

Wie öffne ich das CMS?

Rufen Sie https://kind-pebble-072605b03.7.azurestaticapps.net/cms.html in Ihrem Browser auf. Es wird Chrome oder Edge empfohlen.

Muss ich meine Änderungen speichern?

Nein – alle Änderungen werden automatisch gespeichert, sobald Sie ein Feld verlassen oder einen Button klicken. Es gibt keinen separaten Speichern-Button.

Warum sehe ich „Verbindungsfehler"?

Prüfen Sie Ihre Internetverbindung. Das CMS benötigt eine aktive Verbindung zum Server. Der Verbindungsstatus wird oben rechts im CMS angezeigt.

Angebote & Flyer

Wie erstelle ich einen Flyer?

  1. Erstellen Sie zunächst Angebote im Angebote-Tab (mit Bildern)
  2. Wechseln Sie zum Design-Tab
  3. Wählen Sie das gewünschte Layout (Magazin oder Classic)
  4. Klicken Sie auf „Einzelflyer" für A4-Blätter oder „Plakat" für ein Poster
  5. Passen Sie bei Bedarf Bilder, Positionen und Effekte an
  6. Drucken oder downloaden Sie das Ergebnis

Wie füge ich zusätzliche Ghost-Kopien hinzu?

Es gibt zwei Wege:

  1. Kontrollleiste: Unter dem Flyer finden Sie rechts die Sektion „Weitere Kopien" mit den Buttons „+ 👻 Ghost" und „+ 📝 Duplikat"
  2. Kontextmenü: Rechtsklick auf den Flyer → „👻+ Ghost-Kopie hinzufügen" oder „📝+ Duplikat-Kopie hinzufügen"

Wie lösche ich eine Kopie wieder?

Entweder über den ×-Button in der Kopien-Liste unter dem Flyer, oder per Rechtsklick auf die Kopie → „Kopie löschen".

Welche Bildformate werden unterstützt?

JPG, PNG und WebP. Bilder werden automatisch skaliert. Für beste Qualität verwenden Sie Bilder mit mindestens 800×800 Pixeln.

Push-Benachrichtigungen

Warum kommen manche Push-Nachrichten nicht an?

  • Der Kunde hat die Benachrichtigungen im Browser deaktiviert
  • Das Gerät war zum Zeitpunkt des Sendens offline
  • Bei Firefox auf Android kann es zu Verzögerungen kommen

Wie oft sollte ich Push-Nachrichten senden?

Maximal 1–2 Mal pro Woche. Zu häufige Nachrichten führen dazu, dass Kunden die Benachrichtigungen deaktivieren.

Tipps & Tricks

Beste Ergebnisse für Flyer-Bilder

  • Verwenden Sie freigestellte Produktbilder (transparenter Hintergrund) für den besten Effekt
  • Helle, farbenfrohe Bilder wirken am besten auf Flyern
  • Der Ghost-Effekt wirkt besonders gut bei Bildern mit klaren Konturen
  • Nutzen Sie die Mausrad-Skalierung für schnelle Größenanpassungen

Workflow für die wöchentliche Aktualisierung

  1. Montag: Wochenplan für die nächste Woche anlegen
  2. Neue Angebote mit Bildern erstellen
  3. Design-Tab: Flyer/Plakat prüfen und drucken
  4. Push-Nachricht an Kunden senden
  5. Optional: News-Beitrag auf „Aktuelles" veröffentlichen
