2. Bestellvorgang (Kunde → System)

Der Kunde füllt den Warenkorb, wählt einen Abholtermin und sendet die Bestellung ab. Das System validiert, speichert und benachrichtigt.

(Datum + Zeitslot) K->>API: POST /shop-order
+ JWT + Positionen + Slot API->>API: JWT verifizieren API->>DV: Mindestbestellwert laden
(dl_seiteninhalt) DV-->>API: shop_mindestbestellwert API->>API: Betrag prüfen ≥ Minimum API->>API: Bestellnummer generieren
DL-YYYYMMDD-XXXX API->>DV: POST dl_shopbestellungs
Status = 0 (Neu) DV-->>API: 201 Created API->>Mail: E-Mail: Bestellbestätigung Mail-->>K: 📧 Bestätigung + Positionen API->>API: Push-Notification senden API-->>K: ✅ {bestellnummer, abholdatum} K->>K: Bestätigung anzeigen
